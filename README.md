# 박진원 👋

사용자에게 보기 좋은 화면과 자연스러운 사용 흐름을 만드는 데 관심이 있습니다.  
웹 퍼블리싱 감각을 바탕으로 Java/Spring 기반 웹 개발도 함께 공부하며,  
UI와 기능을 함께 이해하는 웹 개발자로 성장하고 있습니다.

---

## About Me

- 메인 화면, 공통 UI, 레이아웃 구성에 관심이 많습니다.
- JSP/Servlet, Spring 기반 웹 프로젝트를 경험했습니다.
- 웹 퍼블리싱과 백엔드 흐름을 함께 이해하려고 노력하고 있습니다.
- 팀 프로젝트에서 맡은 역할을 끝까지 구현하고 정리하는 것을 중요하게 생각합니다.

## Projects

### 1. Share Diary
JSP/Servlet 기반의 일기장 웹 프로젝트입니다.  
개인 일기, 공유 일기, 교환 일기 기능을 구현한 팀 프로젝트입니다.

**담당한 부분**
- 메인 페이지 index CSS 및 레이아웃 작업
- 메인 페이지 게시판 데이터 출력
- 공통 banner / menu / navigation bar 구성 및 구현

**배운 점**
- 메인 화면 구성과 사용자 동선 설계
- 공통 UI 요소 정리와 스타일 통일
- 여러 페이지가 연결되는 웹 프로젝트 흐름 이해

🔗 [Repository 바로가기](https://github.com/Paengnyeon/Share-Diary)
