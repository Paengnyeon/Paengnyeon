## Projects

### 1. Mood Diary

Java와 PostgreSQL을 활용한 콘솔 기반 감정 일기 & 소비 기록 관리 프로그램입니다.
하루의 감정과 일기를 기록하고, 소비 내역까지 함께 저장할 수 있도록 구성했습니다.

**주요 기능**

* 일기 작성 / 조회 / 수정 / 삭제
* 감정별 일기 검색
* 감정별 일기 통계 조회
* 소비 기록 작성 / 조회
* 카테고리별 소비 합계 조회
* 월별 소비 합계 조회

**사용 기술**

* Java
* PostgreSQL
* JDBC
* Eclipse

**배운 점**

* Java 콘솔 프로그램 구조 설계
* JDBC를 활용한 PostgreSQL 연동
* DAO 구조를 통한 DB 접근 로직 분리
* CRUD와 SQL 통계 함수 활용
* 
🔗 [Repository 바로가기](https://github.com/Paengnyeon/thein_ProJ_MoodDiary_consol)
